Scaling boundary

20,407 items revealed
the next design constraint.

ERROR: request entity too large
Returned items: 20,407
Large raw-row model input exceeded the practical request boundary.
Target redesign

Aggregate outside the model

  • Calculate counts and aggregates outside the model
  • Send a compact validated summary for explanation
  • Use the model for interpretation, not raw-row processing
  • Require approval before the email action
Before → after

From raw rows to a validated summary.

Current constraint

Raw-row model input

Large raw-row input can exceed request limits and makes the workflow unsuitable for larger datasets.

Target architecture

Compact validated context

External aggregation produces a compact summary. The model explains it, and an approval step precedes the Gmail action.
